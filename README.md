# Hospůdka u Havlů

Jednoduchý statický web (HTML + CSS), hostovaný přes GitHub Pages z účtu `nedvidekm`:
https://hospudkauhavlu.cz/

- `index.html` – obsah stránky (místa k doplnění jsou označená komentářem `DOPLNIT`)
- `style.css` – vzhled
- `img/` – originální fotky od Tomáše, `img/web/` – zmenšené verze použité na webu

Vlastní doménu (registrovanou na majitele hospůdky) přidáme později souborem `CNAME`.
